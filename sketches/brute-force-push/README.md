# BRUTE FORCE / PUSH

An interactive Studio 01 study of collective persistence, local damage, and regeneration. [Open the sketch](index.html) · [Sketch gallery](../index.html).

Thousands of small independent particles move toward a resistant wall. Repeated impacts weaken individual squares until passages emerge. Each square can gradually rebuild when the local pressure subsides; a breach is therefore not necessarily permanent. Openings alter the paths of arriving particles, creating a changing contest between pressure and recovery. This is an abstract computational visualization, not a physical materials model.

**Interact:** touch or drag in the square field to focus the swarm at a height. Release focus to return to autonomous searching. **Swarm force**, **Barrier resistance**, and **Square recovery** sliders change the balance. **Pause** and **Reset** are available. With keyboard focus on the canvas: Space pauses, Enter focuses the center, arrow keys adjust the focus, and Escape releases it. Reduced-motion preferences start paused. Everything runs locally in one HTML file without external dependencies.

The black background, subtle grid and monochrome square elements take visual cues from the VIRSMAS study, but this is a distinct exploration of brute force through pushing. Developed in [min1](https://github.com/mantascc/min1/tree/main/studio-01/sketches/brute-force-push); this public page is a selected snapshot.
