# Presence atlas / 100days — exploration 03 + 04

Two pages for [min1 issue #5](https://github.com/mantascc/min1/issues/5), redrawn inside the 100days visual language (computational minimalism, Clear Channel tokens).

- [index.html](index.html) — **exploration 03, open survey.** Ten directions across six construction categories, each descended from numbered 100days sketches (orbital ← 06, instrument ← 79, field ← 41/42, stack ← 40/82, lattice ← 51/16/09, ascii ← 53/55/66, trace ← 04/49/11, flock ← 02/74, automaton ← 18/15, sprite ← 89/91). Eight variations per direction (k1–k2 kawaii, p1–p2 playful, f1–f2 functional, b1–b2 bauhaus) = 80 studies. Idle / working / attention / failure for every study, void and paper grounds, 64/128 px, a detail sheet with 16–64 px previews on both grounds, seed stepping, vibe re-skinning, a Bayer-dither state morph and a copyable recipe.
- [matrices.html](matrices.html) — **exploration 04, Matrices deep dive.** Editable matrix with symmetry orbits; grammar sweeps (size × symmetry, density × skin); a 48-agent population with Hamming-distance confusability, rejection sampling and hue separation; state as grid operations (keeps / bends / breaks identity); cell-flip morph orders and gravity failure; pixel-snapped 12–64 px scale plus three large-asset treatments (recursion, dither, blueprint).

## Rules carried over from 100days
Circles, lines and rects only; grid placement; monospace lowercase labels; 12 fps stepped motion; dithering instead of gradients; no radius or shadow.

## Rules bent for identity
Six OKLCH hues + ink instead of one accent (same hue angle on both grounds, lightness swapped); a paper ground beside the void; touch instead of hover; eyes allowed at the kawaii end.
