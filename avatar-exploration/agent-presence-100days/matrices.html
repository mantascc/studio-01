matrices / deep dive

Identity through occupancy. An agent is a small grid of cells; which cells are on is who it is. This page takes the matrix apart: its grammar, how many distinct agents it can hold before two look alike, which grid operations express state without losing the identity, how one matrix morphs into another, and what it becomes when it grows from 12 px to a poster. Everything below reads from the matrix you edit in chapter 01.

grammar
Three choices define the space: grid size, symmetry, density. Then a skin decides how a cell is drawn. Each row below shares one seed, so a column change is the only thing that varies.

03
population
Forty-eight agents from the current grammar at 32 px. Pairs that differ by two cells or fewer are flagged: at a glance they are the same agent. Rejection sampling and hue separation are the two fixes.

  

  

  






  
04
state as a grid operation
Every state is an operation applied to the identity. Some keep the identity whole, some bend it, one destroys it on purpose. Tap one per row to choose your state set; the editor and the scale chapter use it.

  






  
05
morph
Between two matrices the only honest morph is flipping cells. The order of the flips is the expression: reading order is mechanical, radial grows from the core, random dissolves, sweep scans. Gravity is the morph into failure.

06
scale
The interface sizes are pixel-snapped: a cell is always a whole number of device pixels, so nothing goes soft. Larger assets add detail inside the cells, so the identity stays the same shape at every size.

  

  

    
    
    
  






  
07
first read
Design judgments from building this, not user-tested.

  

    
sweet spot
5×5 mirror, density ~0.5
Fifteen free cells give 32,768 identities, enough for any team, and mirror symmetry reads as a figure rather than noise. 4×4 is too small a space; 7×7 and up turns to texture at 32 px.

    
states
stripe, frame, drop
Working by stripe and attention by frame keep every cell where it was, so the agent is recognisable mid-state. Drop is the right failure because it reads as collapse and is fully reversible by its own morph.

    
open
shape first, colour second
With rejection at distance three, no two agents in a population of forty-eight are confusable by shape alone. Colour then becomes a second key, not the only one. Next: test with real agent names and a hue per role.
